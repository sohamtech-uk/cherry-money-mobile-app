# Cherry Money Mobile App

Ionic/Angular Capacitor mobile application for Cherry Money.

## API

The app uses:

```text
Development: https://dev.cherrymoney.co.uk/api/
Production: https://cherrymoney.co.uk/api/
```

Configure the API base URL in:

- `src/environments/environment.ts`
- `src/environments/environment.prod.ts`

## Development

```bash
npm install
npm run build
```

Native app metadata is configured through Capacitor plus the Android and iOS platform folders.
